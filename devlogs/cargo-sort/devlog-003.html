Development Update #3

King Skyline [DHC]

This has been one of the biggest updates since development began. While there aren't many flashy new gameplay mechanics this time around, almost every major system has been rebuilt behind the scenes to make Cargo Router far more scalable, easier to maintain, and ready for future content.

A lot of this work won't be immediately visible to players—but it's some of the most important development I've done so far.

🏗️ A Completely Data-Driven Game

One of the biggest goals for this update was removing hard-coded systems and replacing them with a flexible, data-driven architecture. Instead of every upgrade, difficulty setting and game rule being written directly into the code, they're now controlled through dedicated data assets inside Unity.

Want a new upgrade? No coding required. Want a completely new game mode? Create a new configuration. Want to rebalance the economy? Adjust a few values instead of rewriting scripts. This change gives Cargo Router a much stronger foundation as development continues.

🛒 The Shop Has Been Rebuilt

Previously, every upgrade button had to be created and maintained manually. Now the shop builds itself automatically. Every available upgrade is generated directly from its own data, meaning new upgrades can be added in just a few clicks without redesigning the interface.

📈 Better Progression

Progression is now modular. A dedicated upgrade system handles costs, levels, diminishing returns, and save data from one central location. The result is a cleaner codebase and a progression system that's much easier to expand.

🎮 Introducing Proper Game Modes

Cargo Router now supports multiple game modes through a completely configurable system. Rather than simply increasing package speed, each mode controls shift duration, spawn rates, multipliers, starting shields, and maximum mistakes allowed.

🟢 Easy

Perfect for learning the game.

  • • More breathing room
  • • Bonus starting shields
  • • Unlimited mistakes

📦 Fine Tuning the Package Economy

Each package type has been reviewed to better fit the new difficulty system. Standard packages remain your reliable source of income. Fragile packages now feel much riskier, forcing split-second decisions when the pace increases.

Priority packages continue to offer huge rewards—but equally painful penalties if missed. Golden packages remain the rare jackpot that can completely change the outcome of a run. Balancing these across every difficulty should make each shift feel exciting from start to finish.

🖥️ Smoother User Experience

After completing a shift, players can now move seamlessly between the Shift Report and the Upgrade Shop without awkward transitions. The shop layout has also been redesigned so longer upgrade descriptions fit neatly inside each card while remaining easy to read.

🐞 Bug Fixes & Stability

  • ✅ Fixed panel hierarchy issues causing menus to close unexpectedly.
  • ✅ Fixed game modes resetting after replaying a shift.
  • ✅ Improved save handling for upgrades and progression.
  • ✅ Cleaned out older legacy systems that are no longer needed.

🔧 Looking Ahead

With the architecture now in a much healthier place, future updates can focus far more on creating content rather than rebuilding systems.

  • 📦 New upgrades
  • 🚚 Additional game modes
  • 🏭 More layouts
  • ⚡ New package types
  • 🎯 Extra mechanics
  • 🏆 More progression

The heavy lifting behind the scenes is finally paying off. Every update brings Cargo Router closer to feeling like a complete arcade experience rather than just a prototype. Building these scalable systems now means future content will be much faster to develop, easier to maintain, and far more ambitious.

Thanks to everyone following the development journey—I can't wait to show you what's coming next! 🚛📦
