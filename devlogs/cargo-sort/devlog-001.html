Development Update #1

King Skyline [DHC]

It's been a very productive few days, so I thought I'd share where Cargo Sort currently stands. For anyone who hasn't seen the project before, Cargo Sort is a small, fast-paced 2D arcade logistics game built in Unity 6. The goal is simple: sort incoming packages into the correct loading bays before they reach the end of the conveyor belt.

It's designed to be easy to pick up but increasingly frantic as each shift progresses. The project is also serving as my first complete Unity game while I continue learning C# and building towards my much larger project, Trucks & Automation.

🏗️ Building the Foundations

Rather than rushing straight into gameplay, I spent time building a solid foundation first. The project now has a clean modular architecture, with game logic, UI, audio and data all separated properly.

Instead of hardcoding values throughout the project, package types are created using Unity ScriptableObjects, making it incredibly easy to expand the game later without rewriting systems.

✔ Everything is event-driven too, meaning the UI only updates when something actually changes instead of constantly checking every frame.

📦 The Core Gameplay Is Working

The warehouse is now fully operational. Packages spawn automatically onto the conveyor belt and travel towards three loading bays. Each package knows exactly which lane it belongs to, and players can quickly redirect them using either the keyboard or mouse.

Correct deliveries earn money and build combo multipliers, while mistakes reduce your earnings and reset your streak. The basic gameplay loop is now fully playable from start to finish.

🎮 A Complete Arcade Loop

Cargo Sort has now evolved from a simple prototype into an actual game. Each shift lasts 60 seconds before the factory shuts down, all conveyor belts freeze, and a Shift Report appears showing:

  • Final Score
  • Money Earned
  • Accuracy & Combo Performance

⚡ Dynamic Difficulty

Instead of remaining the same speed throughout an entire shift, the game now gradually becomes faster and more intense. As time passes:

  • Conveyor speed increases
  • Package movement accelerates
  • Spawn rates increase

🎨 Improved Readability & 💥 Game Feel

Sorting quickly depends on recognising packages instantly. To help with this, every package now uses a dual visual system: Cardboard colour + Unique shipping stamp. The package spawning system has also been rewritten to prevent long streaks of identical boxes.

Correct Deliveries Trigger:

  • ✨ Particle effects
  • 💰 Floating money popups
  • 🔥 Animated combo feedback
  • 🔊 Responsive sound effects

Mistakes Trigger:

  • 📳 Camera shake
  • ❌ Penalty popups
  • 🚨 Warning sounds

📈 Meta Progression & ⚙️ Under the Hood

Money earned during gameplay can now be spent on upgrades, including Wage Boosts, Overtime Clocks, and Insurance Policies (Combo Shields). Every run contributes towards long-term progression.

Behind the scenes, I've continued focusing heavily on code quality. Current highlights include:

  • ✅ Modular architecture
  • ✅ Event-driven systems
  • ✅ Clean ScriptableObject data
  • ✅ Singleton protection
  • ✅ Zero compiler warnings/errors

🚚 What's Next?

The next major milestones include more warehouse events, additional package types, better visual polish, main menu improvements, and Steam release preparation.

Overall, I'm really happy with how quickly the project has come together. What started as a simple learning exercise is already becoming a genuinely fun little arcade game, and every system I build is also teaching me skills that will carry over into Trucks & Automation.

Thanks to everyone following the development so far—there's still plenty more to come! 🚛📦
