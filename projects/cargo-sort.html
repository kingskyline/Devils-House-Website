Cargo Routers

A fast-paced 2D arcade logistics game. Sort the line, build your combo, and survive the shift.

Core Vision

A small, fast-paced 2D arcade logistics game built in Unity 6. The goal is simple: sort incoming packages into the correct loading bays before they reach the end of the conveyor belt. Easy to pick up, but increasingly frantic as each 60-second shift progresses.

Primary Design Goals

  • Frantic 60-second arcade loops
  • Dynamic pacing and difficulty scaling
  • Meta-progression and permanent upgrades
  • Clean, modular, event-driven codebase

Current Progress

Alpha v0.3 is live! The backend has been completely overhauled into a modular, data-driven architecture. The upgrade shop has been fully rebuilt, and dedicated Game Modes (Easy, Standard, Hardcore) have been implemented. Development remains actively focused on Phase 4: Gameplay Expansion.
